## Core Maintainers
* **Worm Evolution Team** — [GitHub Repository](https://github.com/worm-evolution/seim)

## How to Contribute
We welcome contributions from the community! To contribute to SEIM:
1. Fork the repository and create your branch from `main`.
2. Ensure all unit, stress, and integration tests pass cleanly with `npm test`.
3. Submit a Pull Request detailing the changes, telemetry improvements, or optimizations made.
